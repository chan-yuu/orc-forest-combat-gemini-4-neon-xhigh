# 林海斩兽 · 剑盾战魂（3D 森林动作战斗 Demo）

基于 HTML5 + Three.js（CDN 动态引入，零本地依赖库）构建的 3D 动作战斗 Demo。

- **在线试玩（GitHub Pages）**：https://chan-yuu.github.io/orc-forest-combat-gemini-4-neon-xhigh/

## 核心战斗机制

- **近身积怒 → 怒气点（最多 3 点）**：近身三连斩与举盾/精准格挡积蓄怒气槽（`0%–100%`）；怒气槽满 `100%` 自动点亮 1 个怒气点，技能仅消耗怒气点释放。
- **1 怒气点 · `1 / Q` 盾击突进**：持盾高速突进并眩晕打断敌方蓄力，随后 3 次近战回怒 `+35%`。
- **2 怒气点 · `2 / E` 连锁飞盾**：远程掷出战盾，类似连锁闪电自动追踪弹射撞击附近最多 2 名敌人并减速，随后回旋飞回手中。
- **3 怒气点 · `3 / R` 旋风斩**：消耗 3 点开启可自由移动的烈焰旋风斩，霸体减伤 `50%` 持续切割周围敌人并终结爆发。
- **森林战场与敌人**：包含**半兽人战士**与拥有多段预警技（重斧横扫、战吼震地、裂地冲锋）及二阶段狂暴机制的**半兽统领（Boss）**。

## 操作方式

- `WASD` / 方向键：移动
- `鼠标左键` / `J`：近战三连斩
- `按住鼠标右键`：举盾格挡 / 精准弹反（瞬间大量回怒）
- `空格` / `Shift`：无敌翻滚闪避
- `1/Q`、`2/E`、`3/R`：释放对应怒气点技能
- `鼠标滚轮`：调整视距
