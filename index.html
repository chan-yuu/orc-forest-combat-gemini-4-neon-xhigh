战斗机制与按键

移动 / 视角：WASD 或方向键移动，鼠标指向即攻击/技能方向，滚轮可微调视距。
近身三连斩（左键 / J）：核心怒气来源，第三段重斩回怒最高；同时命中多个敌人获得额外怒气。
举盾格挡（按住右键）：正面减伤 75% 并少量回怒；在受击瞬间 0.28 秒内举盾触发精准格挡，免疫伤害、震退敌人并瞬间获得 +45 怒气！
战术闪避（Space / Shift）：短暂无敌翻滚，用于躲避半兽统领的震地或冲锋。
[1 / Q] 盾击突进（1 怒气点）：突进贴脸 + 眩晕 1.3 秒 + 3 次近战回怒提升 35%。
[2 / E] 连锁飞盾（2 怒气点）：远程掷盾，连锁追踪撞击附近最多 2 个敌人并减速，然后自动飞回手里。
[3 / R] 旋风斩（3 怒气点）：可自由移动的大范围持续旋风斩，期间霸体并减伤 50%，终结爆发。
